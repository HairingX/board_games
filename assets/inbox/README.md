# Inbox

Put new art, sound or music here to bring it into the games: a zip file or loose files,
uploaded on GitHub with "Add file" → "Upload files" (up to 25 MB a file), or copied in with
GitHub Desktop for anything larger.

What happens next, each time:

1. The licence is checked: only material free to use (such as CC0) is kept, with its licence.
2. The pack is unpacked into `assets/<pack name>/` beside its licence and a note of where it
   came from.
3. The inbox is emptied again.

Only the files a game uses end up in the published app.
